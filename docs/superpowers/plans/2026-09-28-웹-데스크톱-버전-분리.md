# 웹 버전과 데스크톱 버전 분리 구현 계획

설계: `docs/superpowers/specs/2026-09-28-웹-데스크톱-버전-분리-설계.md`
작업 브랜치: `웹-데스크톱-분리`

| 태스크 | 이름 | 설계 항목 | 언어 | 검증 방법 |
|---|---|---|---|---|
| 1 | 폴더 분리와 데스크톱 회귀 확인 | a), b) | 파이썬(이동만) | `desktop_version/` 안에서 전처리와 추론 결과가 이동 전과 같은지 확인 |
| 2 | 가중치 내보내기 | c) | 파이썬 | 파라미터 421,642개, 파일 1,686,568바이트, 다시 읽은 값과 원본 일치 |
| 3 | 검증 데이터 만들기 | e) 정답 데이터 | 파이썬 | 파이썬 경로 정확도 출력 |
| 4 | 자바스크립트 순전파 | d) 순전파, e) 검증 페이지 | 자바스크립트 | 200장 확률의 최대 절대차 1e-4 이하 |
| 5 | 자바스크립트 전처리와 전체 정확도 | d) 전처리, e) 정확도 | 자바스크립트 | 200장 중 97% 이상 정답 |
| 6 | 웹 앱 화면 | f), a) 파일 목록 | JS, HTML, CSS | 브라우저에서 그려서 상위 3개 후보 표시 |
| 7 | 문서 3개 | g) | 마크다운 | 세 파일의 명령을 그대로 실행해 동작 |

태스크 1~3은 파이썬 쪽 준비, 4~6은 자바스크립트 구현, 7은 문서다.
검사 수단(태스크 3의 정답 데이터)을 구현(태스크 4, 5)보다 먼저 만든다.

## 설계 문서 수정

- 텐서 개수: 층 4개 × (weight, bias) = 8개.
