# 손글씨 숫자 인식 (MNIST)

마우스로 숫자를 그리면 PyTorch로 학습한 합성곱 신경망이 0~9 중 어떤 숫자인지 알아맞히는 데스크톱 앱입니다.

## 파일

| 파일 | 역할 |
|---|---|
| `model.py` | 신경망 구조 정의 (`숫자인식망`) |
| `preprocess.py` | 그림을 MNIST 모양(28x28)으로 바꾸는 전처리와 정규화 상수 |
| `train.py` | MNIST 학습 후 `mnist_cnn.pt` 저장 |
| `app.py` | tkinter 그림판 앱 |
| `손글씨인식.pyw` | 윈도우에서 더블클릭하면 명령 창 없이 앱 실행 |
| `mnist_cnn.pt` | 학습된 가중치 |

## 준비

```
py -m pip install torch torchvision pillow numpy
```

(맥은 `py` 대신 `python3`)

## 실행

```
py train.py   # 학습 (이미 mnist_cnn.pt 가 있으면 생략 가능)
py app.py     # 앱 실행
```

## 학습 결과

| 에폭 | 학습률 | 학습 평균 손실 | 시험 손실 | 시험 정확도 |
|---|---|---|---|---|
| 1 | 0.00100 | 0.7748 | 0.0763 | 97.53% |
| 2 | 0.00070 | 0.4694 | 0.0490 | 98.39% |
| 3 | 0.00049 | 0.3975 | 0.0370 | 98.73% |
| 4 | 0.00034 | 0.3647 | 0.0330 | 98.76% |
| 5 | 0.00024 | 0.3442 | 0.0310 | 98.96% |
| 6 | 0.00017 | 0.3304 | 0.0295 | 98.93% |

학습 때만 회전, 이동, 확대/축소, 기울임, 획 굵기(팽창/침식) 증강을 넣습니다. 그래서 학습 손실이 시험 손실보다 큽니다.
처음 3에폭, 증강 없이 학습했을 때는 MNIST 시험 정확도가 99.13%로 조금 더 높았지만, 사람이 그린 것처럼 만든 숫자(크기, 기울기, 획 굵기를 바꾼 500장)에서는 95.2%였습니다.
증강을 넣고 6에폭 학습한 지금 모델은 같은 500장에서 99.2%입니다.
