# desktop_version/CLAUDE.md

손글씨 숫자 인식의 데스크톱(파이썬) 버전. 이 폴더의 파일을 다룰 때 루트 CLAUDE.md에 더해 읽는다.

## 개요

PyTorch로 학습한 CNN(`model.py`의 `숫자인식망`)을 tkinter 그림판(`app.py`)에서 불러 쓴다.
웹 버전이 쓰는 가중치 파일도 이 폴더의 스크립트가 만든다.

## 실행 명령 (모두 이 폴더 안에서)

- 패키지 설치: `py -m pip install torch torchvision pillow numpy` (맥: `python3 -m pip ...`)
- 학습: `py train.py` → `mnist_cnn.pt` 생성. CPU에서 에폭당 수십 초~수 분, 3에폭.
- 앱: `py app.py`. 윈도우에서는 `손글씨인식.pyw` 더블클릭으로 명령 창 없이 실행.
- 가중치 내보내기: `py 가중치내보내기.py` → `../web_version/가중치.bin`, `../web_version/가중치정보.json`
- 검증 데이터 만들기: `py 검증데이터만들기.py` → `../web_version/검증데이터.json` (깃에 넣지 않음)

## 환경 제약

- `train.py`와 `검증데이터만들기.py`는 상대 경로 `data/`에 MNIST(약 11MB)를 내려받는다. 이 폴더로 옮긴 뒤로는 반드시 `desktop_version/` 안에서 실행한다. 코드는 고치지 않았다.
- 학교망 등에서 `CERTIFICATE_VERIFY_FAILED`가 나면 `train.py`가 SSL 검증을 끄고 한 번 더 시도한다.
- 학습이 도는 동안 같은 스크립트를 다시 실행하지 않는다. 프로세스 두 개가 CPU를 나눠 쓰면 둘 다 멈춘 듯 느려진다.

## 파일 간 결합

- `app.py`, `train.py`, `가중치내보내기.py`, `검증데이터만들기.py` 모두 `model.py`의 `숫자인식망`을 쓴다. 층 구조를 바꾸면 다시 학습하고, 가중치를 다시 내보내고, `../web_version/모델.js`도 같이 고친다.
- 정규화 상수(0.1307, 0.3081)는 `preprocess.py`에만 적는다. 웹 버전은 `가중치정보.json`을 통해 이 값을 받는다.
- 전처리 3단계(여백 자르기 → 비율 유지 20x20 축소 → 무게중심을 28x28 중앙으로 이동)는 MNIST 원본의 제작 방식과 같아야 인식률이 유지된다. `preprocess.py`를 바꾸면 `../web_version/전처리.js`도 같이 고치고 검증 데이터를 다시 만든다.
- 반올림은 `반올림()`(0.5를 항상 올림)으로 한다. 파이썬 내장 `round()`는 0.5를 짝수로 보내 자바스크립트와 결과가 달라진다.
- 앱의 그림판은 흰 바탕에 검은 글씨로 보이지만, 모델에 넘기는 그림은 MNIST처럼 검은 바탕에 흰 글씨다.
